What is Hashing?
A hash function takes input and produces a fixed-length output. It's a one-way function — you cannot reverse it mathematically.

Why MD5 is Broken
MD5 has known collision vulnerabilities. But more importantly: passwords are often common words. Rainbow tables contain precomputed hashes of millions of common passwords.

The Attack
Instead of trying to mathematically reverse the hash, attackers try common passwords: password123, admin, monkey, etc. If the plaintext is in their dictionary — instant match.

Defense: Salting
Modern systems add a random "salt" to the password before hashing. Now the same password produces different hashes, making rainbow tables useless.

Connection to Labs
This mirrors the hashing lab in CrypTool where you computed MD5 and SHA hashes. The attack demonstrates why secure password hashing requires salt + strong algorithms (bcrypt, scrypt, argon2).
