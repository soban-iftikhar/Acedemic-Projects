Vulnerability Intel

The Problem DH Solves
How do two parties establish a shared secret over an insecure channel without ever meeting? Classical encryption requires both sides to know the key first.

DH Concept
Each party has a private key (known only to them) and a public value (broadcast). The genius: S = Ba mod p = Ab mod p. Different paths, same answer.

Discrete Logarithm
Security relies on: it's easy to compute gx mod p, but extremely hard to find x given gx mod p. This is the discrete logarithm problem.

Real-World Use
TLS/HTTPS uses DH (or Elliptic Curve DH) to establish session keys. HTTPS connections use ECDH key exchange thousands of times per second globally.

Connection to Labs
This mirrors the DH exchange lab in class. Real DH uses 2048+ bit primes. With such large numbers, even quantum computers would struggle to break it.
