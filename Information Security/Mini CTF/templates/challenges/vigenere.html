Ciphertext: RIJVS{j4g3u3t3_m4ynh3t_nh4mz3x}
Key: CRYPTO

Vigenere Decryption Formula

For each letter:
plaintext[i] = (ciphertext[i] - key[i % keylen]) mod 26

Vigenere Reference Table

A=0 B=1 C=2 ...M=12 ...Z=25

Important Notes:
• Only alphabetic characters are encrypted
• Numbers, symbols, and {} are NOT encrypted
• The key repeats cyclically
• Case: treat uppercase and lowercase normally (A-Z, a-z)

Decryption Process

Example with first few characters:
R - C = 17 - 2 = 15 = P
I - R = 8 - 17 = -9 mod 26 = 17 = R
J - Y = ... (continue pattern)

Vulnerability Intel

Monoalphabetic vs Polyalphabetic
Caesar cipher (shift by fixed amount) is monoalphabetic: 'A' always becomes 'D'. Vigenere uses multiple shifts (polyalphabetic): 'A' becomes different letters depending on key position.

Why Vigenere is Stronger
Frequency analysis fails. In English, 'E' is most common, but in Vigenere ciphertext, each letter appears with similar frequency — the key destroys statistical patterns.

Breaking Vigenere: Kasiski Examination
If the same plaintext appears with the same key alignment, the ciphertext repeats at intervals equal to multiples of the key length. Cryptographers use this to find key length, then treat each shift separately.

Historical Significance
Vigenere was considered unbreakable for 300 years. It was finally broken in the 1860s. This cipher was used in WWI and even some WWII communications.

Connection to Labs
This mirrors the CrypTool classical ciphers lab. Modern encryption (AES, RSA) uses mathematical principles that can withstand all known attacks forever (with sufficient key sizes).
